# MLBB Stats API

Вход по коду из игры → профиль игрока → статистика по сезонам или за всё время.

Адрес API: **`https://mlbb-stats.ru/api/v1`**. Все пути ниже добавляются к этому адресу.

## Перед началом

Получите ключ у MLBB Stats: [partners@mlbb-stats.ru](mailto:partners@mlbb-stats.ru).

Делайте запросы со своего сервера. В каждый запрос добавляйте заголовок:

```http
X-API-Key: ВАШ_КЛЮЧ
```

Ключ нельзя размещать в коде браузера или публиковать в Git.

## 1. Отправить код в игру

Игрок вводит свой ID и номер сервера. С его согласия отправьте:

```http
POST /auth/send-code
Content-Type: application/json

{"playerId":12345678,"serverId":1234}
```

В ответе возьмите **`data.challengeId`** — он понадобится для проверки кода. Код придёт в игру. На ввод есть 5 минут и до 3 попыток.

## 2. Проверить код и войти

```http
POST /auth/verify
Content-Type: application/json

{"challengeId":"ID_ИЗ_ПРЕДЫДУЩЕГО_ОТВЕТА","code":"КОД_ИЗ_ИГРЫ"}
```

В ответе:

- **`data.accessToken`** — токен игрока, действует 24 часа.
- **`data.player`** — его базовый профиль.

Сохраните токен на своём сервере. Для запросов от имени игрока добавляйте второй заголовок, вместе с `X-API-Key`:

```http
Authorization: Bearer ТОКЕН_ИГРОКА
```

## 3. Получать данные

В примерах `12345678-1234` — это **ID игрока + дефис + номер сервера**. Замените на нужный аккаунт.

| Что нужно | Запрос |
| --- | --- |
| Свой профиль и статус Premium | `GET /auth/me` |
| Профиль по ID | `GET /players/12345678-1234` |
| Общие метрики за всё доступное время | `GET /players/12345678-1234/stats` |
| Список сезонов | `GET /players/12345678-1234/seasons` |
| Метрики одного сезона, например 42-го | `GET /players/12345678-1234/seasons/42` |
| Герои и их статистика | `GET /players/12345678-1234/heroes` |
| Выйти из текущей API-сессии | `POST /auth/logout` |

Результат находится в **`data`**, служебная информация — в `meta`. У выхода ответ `204`, без тела.

Токен обязателен для `/auth/me` и `/auth/logout`. Для чтения известных публичных профилей достаточно ключа приложения. Подробности прошлых сезонов доступны только с токеном **владельца аккаунта и его активным Premium**.

## Если нужны только отдельные показатели

Например, только количество матчей и винрейт:

```http
GET /players/12345678-1234/stats?fields=games,winRate
```

Пример ответа с сокращённым `meta`:

```json
{
  "data": { "games": 120, "winRate": 55 },
  "meta": { "requestId": "example-request-id" }
}
```

`55` означает 55%. Для статистики только рейтинговых игр добавьте `mode=ranked`:

```http
GET /players/12345678-1234/stats?mode=ranked&fields=games,winRate
```

## Что важно знать

- Лимит приложения: **30 запросов в минуту, 1000 в сутки UTC**, до 2 одновременно. Дополнительно есть ограничения отправки и проверки кодов.
- Если пришёл `429`, подождите время из заголовка `Retry-After` — оно в секундах.
- Ошибка находится в `error.code`. Например, `invalid_code` — неверный код, `invalid_api_key` — проблема с ключом.
- `null` означает «данных нет», а не нулевой результат. Не вся история может быть доступна; данные обновляются в фоне.
- Если профиль неизвестен сервису, возможен `404 player_not_found`. Предложите владельцу войти через код.
- Истёк токен — повторите вход. Refresh token пока нет.
